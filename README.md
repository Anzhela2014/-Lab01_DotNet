### Ответы на вопросы
1. **Чем Write отличается от WriteLine?**  
    Write оставляет курсор на той же строке, а WriteLine сразу переносит его на новую строчку

2. **Что будет, если в int записать 3.14?**  
   Будет ошибка компиляции. int — только для целых чисел, дробь туда не влезет

3. **Почему 10 / 3 дает 3, а не 3.333? Как получить дробь?**  
   Потому что оба числа целые, и C# просто выкидывает остаток. Чтобы была дробь, надо дописать double: (double)10 / 3

4. **Что такое var и чем отличается от Питона?**  
   var—это когда C# сам угадывает тип переменной при создании, но потом его нельзя менять. В Питоне тип переменной можно менять прямо на ходу как хочешь.

5. **Где используют C# и .NET?**  
   **Microsoft** (для своих сервисов и Windows)
   **Сайт Stack Overflow** (популярен у программистов)
   **Игры на движке Unity** (например, мобильные игры и инди)
